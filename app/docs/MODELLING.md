# Modelling rationale

Engineered, fold-safe tree and linear baselines are primary because labelled datasets are small.
Door combines operation-aware event features with normality evidence. ACV ranks per-car candidates
using within-case residuals. Corrugation emphasizes side-aware spectral features and macro F1. SHM
uses stress-cycle proxies without inventing material constants. Compact neural models are optional
complements, not assumed winners.
